# Professor demonstration (4–6 minutes)

1. **Problem (40 sec).** Different sellers use different size labels; SizeSure compares measurements rather than claiming universal fit.
2. **Profile (80 sec).** Open the homepage, create a profile with fictional chest 92 cm, waist 76 cm and hip 98 cm, Regular fit. Demonstrate a blank or negative-value error and recovery. Save, then reopen the profile.
3. **Chart (90 sec).** Select Compare seller chart. Enter fictional Seller A / Everyday top and S/M/L circumference rows. Example M chest 37 in. Save.
4. **Evidence (60 sec).** Point out that 37 in = 93.98 cm, and the difference from 92 cm is +1.98 cm. This arithmetic is not proof of physical fit.
5. **Guidance (40 sec).** Show `RULES_UNAPPROVED`. Explain that the team must obtain approved fit thresholds before claiming a recommended size.
6. **Close (30 sec).** Show mobile layout, privacy disclosure, and actual test evidence.

## 90-second backup

Show home → profile → chart → comparison → guidance. Explain manual data, exact conversion, no invented rules, and MySQL storage. If backend unavailable, a screenshot is a visual fallback only, not proof of running code.
